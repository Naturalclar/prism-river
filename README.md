# Prism River

ブラウザだけで完結するマルチトラック音声エディタ。音声ファイルをドロップして並べ、ミックスして書き出す。

**サーバーを持たない。** 読み込んだ音声は端末から出ない — アップロードもアカウントも無く、`index.html` を開けば動く。これはプライバシー上の要件であると同時に、このプロジェクトの問い（**サーバー無しの Web でどこまで DAW たりうるか**）そのものでもある。

名前は騒霊三姉妹から。ルナサが弦、メルランが管、リリカが鍵盤を受け持つ編成をそのまま構造に借りていて、トラックの先頭3色はこの3人に対応する。将来のグループバスも同じ3系統で切る予定（下記）。

## 使う

ビルド不要。`index.html` をブラウザで開いて、mp3 / wav / m4a / ogg / flac をドロップするだけ。1ファイル＝1トラック。

| 操作 | |
| --- | --- |
| 再生 / 一時停止 | `Space` またはトランスポート |
| シーク | ルーラーをクリック |
| クリップの移動 | 波形を横にドラッグ |
| 音量 / パン / ソロ / ミュート | 左のトラックヘッダ |

## 今できること

- 複数ファイルの同時読み込みと `decodeAudioData` によるデコード
- Canvas のピーク波形描画（列ごとに min/max を畳む）
- 再生・停止・ループ、シーク、プレイヘッド追従
- トラックごとの音量（`GainNode`）・パン（`StereoPannerNode`）・ソロ・ミュート
- クリップの開始位置を横ドラッグで変更（再生中でも即座に組み直す）
- マスター音量、`AnalyserNode` による L/R レベルメーター、ズーム
- `OfflineAudioContext` によるミックスの一括レンダーと WAV 書き出し

## 計測（2026-08-26 / 44.1kHz ステレオ）

画面下段に出る値。**この数字を出すことがこのツールの主目的**なので、UI を作り替えても同等の情報は残す。

| 項目 | 値 |
| --- | --- |
| sampleRate | 44,100 Hz |
| 出力レイテンシ | 32.0 ms |
| デコード | 2ファイルで 18 ms |
| PCM メモリ | 2トラック4秒で 1.3 MB |
| オフラインレンダー | 4秒のミックスを **12 ms＝実時間の約323倍速** |

最後の行が現時点の一番の収穫。**ミックスダウンは実時間の数百倍で回る**ので、書き出し速度はブラウザだからという理由ではネックにならない。

## 分かっている制約

- **PCM はデコード後 Float32 で保持する。** `長さ(秒) × sampleRate × ch × 4 bytes` なので、10分ステレオ1本で約100MB。トラックが増えるとメモリが先に効く。
- **`decodeAudioData` の対応形式はブラウザ依存。** 読めない形式はその場で伝える作りにしてある。
- claude.ai の Artifact ビューアで開いた場合のみ、`.wav` の保存がビューア側の拡張子許可リストに阻まれる（ブラウザの制限ではない）。このリポジトリから自前でホストする分には関係しない。

## これから

優先度順。検証テーマに効く順で入れ替えてよい。

1. **クリップのトリム** — 左右端をドラッグして頭尻を詰める。DAW として最低限これが要る
2. **フェードイン / アウト** — `GainNode` の `linearRampToValueAtTime`
3. **エフェクト** — `BiquadFilterNode`（EQ）と `DynamicsCompressorNode`。ここが「既存の DAW の代わりになるか」の分水嶺
4. **グループバス** — 弦 / 管 / 鍵盤 の3系統。トラックを3つのサブミックスにまとめて、そこに 3 のエフェクトを挿す
5. **録音入力** — `getUserMedia` + `MediaRecorder`
6. **実時間 webm 書き出し** — `MediaStreamAudioDestinationNode` + `MediaRecorder`

詳しい引き継ぎと未決事項は [`docs/HANDOFF.md`](docs/HANDOFF.md)。
